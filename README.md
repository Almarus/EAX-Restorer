# EAX-Restorer
EAX Restorer — это бесплатное программное обеспечение с открытым исходным кодом, которое удобно автоматизирует использование DSOAL и OpenAL для возвращения старым играм технологии EAX на Windows 10/11.

## Как это работает?

1. Вы просто выбираете `.exe` файл любимой игры детства через удобную кнопку, и она появляется в левой колонке программы.
2. Нажимаете **зелёную стрелку** — *EAX Restorer* сам определит, какой метод нужен игре для активации звука: `DSOAL`, `DSOAL64` или `OpenAL`.
3. Программа скопирует необходимые файлы в папку с игрой, предварительно создав резервную копию оригинальных файлов.

## Безопасность и откат изменений

* Если захотите вернуть всё как было — достаточно нажать **красную стрелку**, и оригинальные файлы игры восстановятся из бэкапа.
* Никакого риска сломать игру, никакой путаницы с разрядностью и версиями.

## Главные преимущества

* Не требует покупки дорогой звуковой карты от *Creative*.
* Работает на любом аудиоустройстве, даже на бюджетных китайских USB-наушниках.
* Полностью безопасна для Steam и прочих лаунчеров.

## Используемые проекты (Credits)

Программа создана с использованием сторонних открытых библиотек и компонентов:
* **[DSOAL](https://github.com/kcat/dsoal)** — эмулятор DirectSound3D через OpenAL (автор *kcat*), восстанавливающий объёмный звук и эффекты EAX.
* **[OpenAL Core SDK](https://openal.org/downloads/)** — программный интерфейс для работы с трёхмерным аудио.
