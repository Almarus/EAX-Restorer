# EAX-Restorer
EAX Restorer — это бесплатное программное обеспечение с открытым исходным кодом, которое удобно автоматизирует использование DSOAL и OpenAL для возвращения старым играм технологии EAX на Windows 10/11.

## Как это работает?

1. **Выбор игры**: Вы просто выбираете `.exe` файл любимой игры детства через удобную кнопку, и она появляется в левой колонке программы.
2. **Активация EAX**: Нажимаете **зелёную стрелку** — *EAX Restorer* сам определит, какой метод нужен игре для активации звука: `DSOAL`, `DSOAL64` или `OpenAL`.
3. **Автоматическая настройка**: Программа скопирует необходимые файлы в папку с игрой, предварительно создав резервную копию оригинальных файлов.

## Безопасность и откат изменений

* **Безопасный откат**: Если захотите вернуть всё как было — достаточно нажать **красную стрелку**, и оригинальные файлы игры восстановятся из бэкапа.
* **Без рисков**: Никакого риска сломать игру, никакой путаницы с разрядностью и версиями.

## Главные преимущества

* **Универсальность**: Не требует покупки дорогой звуковой карты от *Creative*.
* **Доступность**: Работает на любом аудиоустройстве, даже на бюджетных китайских USB-наушниках.
* **Безопасность**: Полностью безопасна для использования и вашей операционной системы.
